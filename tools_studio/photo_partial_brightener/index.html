部分明るく補正（影だけ明るく）

写真の暗くなった部分を指やマウスでなぞるだけ。なぞった場所とその周辺だけがふんわり明るくなります。境界は自動でなじむので、室内写真に入り込んだ影の補正も自然な仕上がりに。

1写真を選ぶ 2影の部分をなぞる 3明るさを調整 4ダウンロード
写真をここにドラッグ＆ドロップ
またはクリックして選択（JPG / PNG / WebP）
ブラシの太さ 選択範囲を色で表示
なぞった部分だけが明るくなります。画質・サイズは元のまま保存されます。

写真はブラウザ内だけで処理され、サーバーには一切送信されません。

こんなときに

・賃貸物件の室内を撮影したら、窓際は明るいのに部屋の隅や家具の陰が真っ暗になってしまった

・写真全体を明るくすると、明るい部分が白飛びしてしまう — 暗いところ「だけ」持ち上げたい

・逆光で手前が影になった外観写真を自然に直したい
