# 物件情報の抜き出し・照合（property_check）

業者から届く物件資料（形式はバラバラ）から、豊川ガイドで管理している項目だけを抜き出し、
サイト（toyokawa-rentallife.com）の掲載内容と照合するための作業フォルダ。

## 目指す仕組み

1. **取り込み**：資料（CSV / Excel / PDF / 写真など）を決まったフォルダに置く
2. **抜き出し**：資料から管理項目だけを建物単位の一覧にする ← `extract_properties.py`（実装済み）
3. **照合**：サイトの掲載物件と比べ、①サイトにない物件 ②所在地などの食い違い ③項目の抜け を出す（未実装）
4. **確認**：結果をスプレッドシートに出し、反映してよい行に人がチェックを付ける（未実装）
5. **更新**：チェック済みの行だけ GitHub Actions でサイト（WordPress）に反映する（未実装）

サイトへの反映は公開操作なので、人のチェックなしには反映しない作りにする。
既存の部品（`light_articles/scripts/` の `wp_client.py`・`sheets_client.py`・`drive_client.py`、
`wp_set_status` ワークフロー）を流用する想定。

## 抜き出す項目

物件名・所在地・築年・構造・階建て・管理会社・種別（＋空室数）。
賃料・間取りなど部屋ごとの条件は対象外。

## 使い方

```
pip install -r property_check/requirements.txt
python property_check/extract_properties.py --input 資料フォルダ --output 物件情報_抜き出し.xlsx
```

出力 Excel のシート:

- **建物一覧**：建物ごとに1行。複数資料に載っている建物は情報を合わせる。要確認の行は黄色
- **資料別の件数**：資料ごとの部屋数・建物数
- **文字化けの読み替え**：元資料で文字化けしていた物件名と、読み替えた名前・確からしさ

## 対応している資料の形式（2026-10-26 時点）

| 資料 | 取れる項目 |
|---|---|
| CSV（Shift-JIS、取引態様,種別,物件名/部屋番号,所在地,…） | 所在地・築年月・種別 |
| Excel「空室一覧表」（1部屋2行、建物CD・構造・完成年月・住所） | 所在地・完成年月・構造・種別 |
| PDF ミニミニ空室一覧 | 所在地・築年 |
| PDF 業者サイト一覧（物件名/部屋番号＋管理会社 …） | 所在地・築年数・階建て・管理会社 |
| PDF リアプロBB+ 空室一覧 | 所在地・築年月・構造・階建て・管理会社 |

複数の資料をつなげた PDF でも、ページごとに形式を見分けて読む。
新しい形式の資料が来たら、`extract_properties.py` に読み取り処理を追加する。
写真・スキャン PDF（文字情報のないもの）は未対応（Claude に直接読ませる運用を検討）。

## 既知の注意点

- **リアプロBB+ の文字化け**：レオパレス物件の名前が元 PDF の時点で化けている（例: `???I?p???X?q`）。
  Shift-JIS の残骸と、他資料の物件名・同じ町・築年を照らして読み替える。
  2026-10-26 の資料では 49 棟中 48 棟を読み替え、1 棟（八幡町東赤土・2006年築）は不明。
- **住所の「丁目丁目」**：リアプロBB+ の住所表記の重複。自動で直す。
- **築年数しかない資料**（「築28年」）は、今年から逆算した概算年（「1998頃」）になる。

## データの扱い（重要）

資料そのものと出力 Excel は**リポジトリに入れない**。
鍵番号・管理会社の連絡先などが含まれるため。`property_check/input/` と `property_check/output/`
は `.gitignore` 済みなので、ローカルで作業するときはそこに置く。
